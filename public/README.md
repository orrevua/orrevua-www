# Public assets

Drop these files in this folder whenever you want to swap them — they're git-tracked and referenced by the site.

## Required files

- **`photo.jpg`** — Your profile photo, shown in the hero section. Recommended: 800x1000 (4:5 ratio), JPG or PNG. If missing, the hero shows "FF" initials as fallback.
- **`resume.pdf`** — Your downloadable resume. Linked from the contact section and the `/resume` terminal command.

## Cleanup

You can safely delete these default Next.js assets if you don't use them:
`file.svg`, `globe.svg`, `next.svg`, `vercel.svg`, `window.svg`
